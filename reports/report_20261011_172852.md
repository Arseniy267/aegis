3. **Векторы атаки:**
   - **FTP (vsftpd 2.3.4)**: CVE-2011-2523 (root shell via ':)')
   - **SSH (OpenSSH 4.7p1)**: CVE-2016-0777 (private key leak), CVE-2018-15473 (user enumeration)
   - **Telnet**: CVE-2022-39028 (NULL pointer dereference), CVE-2021-27171 (root telnetd on port 26/tcp)
   - **SMTP (Postfix smtpd)**: CVE-2024-27305 (inbound SMTP smuggling), CVE-2023-51764 (SMTP smuggling)
   - **DNS (BIND 9.4.2)**: CVE-2008-0122 (DoS via off-by-one)
   - **HTTP (Apache 2.2.8)**: CVE-2017-7659 (DoS via malformed HTTP/2 request)
   - **FTP (ProFTPD 1.3.1)**: CVE-2010-4221 (stack overflow RCE)
   - **MySQL (MySQL 5.0.51a)**: CVE-2012-2122 (authentication bypass via repeated attempts)
   - **PostgreSQL (PostgreSQL DB 8.3.0 - 8.3.7)**: CVE-2013-1900 (memory leak via random number generator)
   - **VNC (RealVNC 4.1.1)**: CVE-2006-2369 (authentication bypass via security type None)

4. **Рекомендации по защите:**
   - **FTP (vsftpd 2.3.4)**: Обновите до версии 3.0.3 или выше.
   - **SSH (OpenSSH 4.7p1)**: Обновите до версии 7.7 или выше.
   - **Telnet**: Удалите Telnet из системы, используйте SSH вместо него.
   - **SMTP (Postfix smtpd)**: Обновите до версии 3.8.6 или выше.
   - **DNS (BIND 9.4.2)**: Обновите до версии 9.16.2 или выше.
   - **HTTP (Apache 2.2.8)**: Обновите до версии 2.4.51 или выше.
   - **FTP (ProFTPD 1.3.1)**: Обновите до версии 1.3.6c или выше.
   - **MySQL (MySQL 5.0.51a)**: Обновите до версии 5.7.38 или выше.
   - **PostgreSQL (PostgreSQL DB 8.3.0 - 8.3.7)**: Обновите до версии 13.12 или выше.
   - **VNC (RealVNC 4.1.1)**: Обновите до версии 6.0 или выше.
