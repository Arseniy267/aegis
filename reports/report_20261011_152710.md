### 3. Векторы атаки — по приоритету

1. **ProFTPD 1.3.1 (CVE-2026-35025)**
   - **Вектор атаки**: Аутентифицированный FTP пользователь может обойти Directory ACL restrictions.
   - **Приоритет**: Высокий. Эта уязвимость позволяет атакующему обходить ограничения доступа, что может привести к дальнейшим привилегированным действиям.

2. **OpenSSH 4.7p1 (CVE-2012-0566)**
   - **Вектор атаки**: Bypass authentication by using a crafted username.
   - **Приоритет**: Высокий. Эта уязвимость позволяет атакующему обойти аутентификацию, что может привести к полному доступу к системе.

3. **Postfix 3.8.5 (CVE-2024-27305, CVE-2023-51764)**
   - **Вектор атаки**: SMTP smuggling.
   - **Приоритет**: Высокий. Эта уязвимость позволяет атакующему внедрять неподтвержденные данные в SMTP трафик, что может привести к дальнейшим привилегированным действиям.

4. **vsftpd 2.3.4 (CVE-2011-2523)**
   - **Вектор атаки**: Bypass the chroot jail by using a symbolic link.
   - **Приоритет**: Средний. Эта уязвимость позволяет атакующему обойти ограничения доступа, что может привести к дальнейшим привилегированным действиям.

5. **telnetd (CVE-2022-39028, CVE-2021-27171)**
   - **Вектор атаки**: NULL pointer dereference or root privilege escalation via CLI commands.
   - **Приоритет**: Средний. Эти уязвимости позволяют атакующему получить привилегированный доступ, что может привести к дальнейшим привилегированным действиям.

### 4. Рекомендации по защите

1. **Обновление ПО**:
   - Обновите все компоненты до последних версий, чтобы избежать известных уязвимостей. Например:
     - vsftpd 2.3.4 -> vsftpd 3.0.3
     - OpenSSH 4.7p1 -> OpenSSH 8.4p1
     - Postfix 3.8.5 -> Postfix 3.9.0
     - ProFTPD 1.3.1 -> ProFTPD 1.3.10

2. **Доступ к FTP**:
   - Отключите FTP, если он не требуется, или настройте его так, чтобы использовать безопасные протоколы, такие как SFTP.

3. **Аутентификация**:
   - Убедитесь, что аутентификация на SSH и FTP настроена правильно и использует сильные пароли.

4. **Firewall и ACL**:
   - Настройте firewall, чтобы разрешать только необходимые порты и ограничивать доступ к ним.

5. **Обучение и мониторинг**:
   - Обучите команду безопасности о безопасности сетей и регулярно мониторьте систему на предмет аномальных действий.

6. **Использование безопасных протоколов**:
   - Настройте SMTP для использования TLS/SSL для шифрования трафика.

7. **Обновление и патчи**:
   - Настройте автоматическое обновление и патчи для всех компонентов системы.

Эти меры помогут уменьшить риски и повысить безопасность системы.
